# Welcome to turboTensor: a NN-training library

It is my personal pytorch, made by me in the summer of 2026. The reason to make it was pretty simple : 
        `I wanted to understand pytorch internals, and understand how big software can be written bit-by-bit`

# Status: 

As of now, I have successfully built a tensor engine with a neural network library on top of it, have tested it on XOR and some other datasets. We can successfully make neural networks and guess what : `It has GPU support!`. 

It is <b>not</b> something which is only for educational purpose and cannot be used with gpus. It works <b>fine with GPUs</b>. Thanks to CuPy!
